# widgets

This layer contains self-contained UI blocks used by pages.

## What goes here

- Independent visual blocks: header, sidebar, dashboard card, summary panel.
- Compositions of features and entities that form a meaningful visual unit.

## What does NOT go here

- Application-wide state or routing logic.
- Generic primitives (those go in `shared`).

## Dependencies

`widgets` can import from `features`, `entities`, `shared`.
